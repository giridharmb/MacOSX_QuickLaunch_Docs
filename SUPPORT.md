# Getting help with QuickLaunch

- **Docs:** https://giridharmb.github.io/MacOSX_QuickLaunch_Docs/docs.html
- **Troubleshooting & FAQ:** https://giridharmb.github.io/MacOSX_QuickLaunch_Docs/support.html
- **Report a problem / request a feature:** [open an issue](https://github.com/giridharmb/MacOSX_QuickLaunch_Docs/issues/new/choose)

Please include your QuickLaunch version (Settings › About) and macOS version. Issues are public, so never post passwords or tokens.
